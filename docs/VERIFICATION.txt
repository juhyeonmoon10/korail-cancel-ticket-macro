코레일 한 장 도우미 PC — 공개 배포 검증 요약
기준: 2026-10-23 KST / v0.8.0

v0.8.0
- JavaScript 검사 125개 및 C# 검사 289개 통과.
- 배포할 v0.8.0 EXE를 직접 실행해 내장 WebView 모의 검사 72개 통과.
  실제 코레일이나 Telegram 요청 없이 조회·선택·중지·로컬 알림 전달을 검사함.
- EXE에 포함된 화면 자산 11개가 공개 소스와 같은지 확인함.
- C# 검사에는 여러 후보 검증 75개와 짧은 Windows 절전 방지 요청·해제 15개를 포함함.
- JavaScript 검사는 쉼표 입력부터 후보 화면 판정까지의 연결 및 기존 단일 선택을 포함함.
- 쉼표로 여러 열차번호를 입력하고, 같은 날짜·구간·등급·총 1명 조건에서
  최대 20편 중 한 편을 예약하는 기능을 추가함. 빈 입력은 기존 드롭다운 한 편을 사용함.
- 현재 조회 결과에 모든 후보가 있어야 하며 입력한 번호 순서대로 확인함.
  가격 선택 이후에는 한 편으로 고정하고 추가 후보를 예약하지 않도록 구성함.
- 여러 행이 있는 로컬 화면으로 첫 후보 매진 후 다음 후보 선택, 입력 순서 우선,
  전체 매진, 후보 누락·중복·조건 불일치·알 수 없는 상태·차단 및 후보 변경을 검사함.
- 화면 판정은 클릭이나 화면 변경 없이 수행하며, 모든 후보가 명확한 매진일 때만
  자동 재조회를 허용함. 기존 좌석 선택이나 예매 영역이 있으면 중지함.
- 이 버전의 실제 코레일 예약과 Telegram 예약 완료 알림은 다시 시험하지 않음.
- 실제 절전 진입과 밤샘 실행은 검증하지 않음. 절전 방지와 최대 10분 제한은 유지함.

검증 범위
한 번의 실제 성공이나 이전 버전의 결과가 모든 열차·사이트 변경·PC 환경에서의
성공을 보장하지 않음. 밤샘 운영은 검증하지 않았으며 자동 조회는 실행당 최대 10분,
간격 30~300초, 추가 조회 1~20회로 제한됨.

예약 완료 알림은 미결제 예약 확인이며 결제 완료를 뜻하지 않음.
미결제 예약은 공식 화면의 결제기한이 지나면 취소될 수 있음.
인증·접근 제한·알 수 없는 안내에서는 자동 동작을 중지함.
서명되지 않은 EXE이므로 Windows에서 실행을 차단할 수 있으며,
다른 PC나 다른 버전의 실행 결과로 현재 환경의 실행 허용을 보장하지 않음.

검사 방법
소스 루트에서 ./run-mock-tests.ps1로 C# 검사를 수행함.
이 명령에는 짧은 Windows 절전 방지 요청·해제 검사가 포함되며 전원 설정을 바꾸지 않음.
JavaScript 검사는 npm install --ignore-scripts 후 npm test로 수행함.
로컬 검사는 실제 예약·Telegram 수신 검사를 대체하지 않음.
