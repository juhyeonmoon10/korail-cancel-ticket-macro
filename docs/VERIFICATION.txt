- 첫 재조회 전과 이전 요청의 결과 확인 완료 후 다음 재조회 전에 대기를 정함.

  후보 최대 20편, 더보기 최대 30회·결과 2,000행 제한도 유지함.

검증 범위
한 번의 실제 성공이나 이전 버전의 결과가 모든 열차·사이트 변경·PC 환경에서의
성공을 보장하지 않음. 밤샘 운영은 검증하지 않음. 현재 v0.8.4는 간격과 추가 조회 횟수에
각각 1~2,147,483,647의 정수를 허용하며 별도 총 실행시간 제한은 없음.
위의 30~300초·1~20회·최대 10분 설명은 해당 이전 버전의 검사 이력임.
현재도 조회·더보기 요청의 결과 확인 기한은 30초이며 요청 중 중복 조회를 보내지 않음.

예약 완료 알림은 미결제 예약 확인이며 결제 완료를 뜻하지 않음.
미결제 예약은 공식 화면의 결제기한이 지나면 취소될 수 있음.
인증·접근 제한·알 수 없는 안내에서는 자동 동작을 중지함.
서명되지 않은 EXE이므로 Windows에서 실행을 차단할 수 있으며,
다른 PC나 다른 버전의 실행 결과로 현재 환경의 실행 허용을 보장하지 않음.

검사 방법
소스 루트에서 ./run-mock-tests.ps1로 C# 검사를 수행함.
이 명령에는 짧은 Windows 절전 방지 요청·해제 검사가 포함되며 전원 설정을 바꾸지 않음.
JavaScript 검사는 npm install --ignore-scripts 후 npm test로 수행함.
로컬 검사는 실제 예약·Telegram 수신 검사를 대체하지 않음.
