코레일 한 장 도우미 PC 0.10.0 실험판 — 사용 안내

Windows용 비공식 개인 예약 보조 프로그램입니다. 결제는 자동으로 하지 않습니다.

안정 버전 0.9.0:

동시 작업 실험판 0.10.0 (별도 프리릴리스):
https://github.com/juhyeonmoon10/korail-one-helper/releases/tag/v0.10.0

설치
1. Releases에서 korail-desktop.zip을 받고 모두 압축 해제합니다.
2. Windows 10/11 x64, .NET Framework 4.6.2 이상, WebView2 Runtime이 필요합니다.
3. 기존 도우미를 닫고 KorailOneHelper.exe를 실행합니다.
4. 새 PC에서는 아래 안내에 따라 본인 Telegram 봇을 연결합니다.

화면 구성
- 왼쪽 메뉴는 코레일 열기, 예약 관리, 설정, 도움말 네 개로 통합했습니다.
- 상단: 선택 열차 시작, 계속, 모두 중지 (F8), 동시 작업 (실험).
- 동시 작업 중 직접 확인할 안내가 생기면 안내 확인 버튼이 표시됩니다.
- 예약 관리에서 예약 순서, 지금 한 번 예약, 예약 기록을 확인합니다.
- 설정에서 여정 필터와 내 텔레그램 연결을 함께 관리합니다.
- 하단: 실행 상태와 텔레그램·절전 방지 상태. 긴 안내는 마우스를 올려 확인할 수 있습니다.
- 사용 안내, 마우스 연습, 진단 저장과 이전 연습 화면은 ‘도움말’에서 엽니다.
- 설정창에서 설명이 아래에 더 있으면 탭 안을 스크롤하세요. ‘설정 저장’은 하단에 있습니다.

다른 앱과 동시에 사용하기 (0.10.0 실험 기능)
1. 실행 전에 상단 동시 작업 (실험)을 체크합니다. 앱을 켤 때마다 기본값은 꺼짐이며 저장하지 않습니다.
2. 선택 열차 시작 또는 예약 순서 시작을 누릅니다. 열차 목록 읽기를 누르기 전에 체크해도 적용됩니다.
3. 다른 앱을 클릭하거나 키보드로 입력하고 Alt+Tab으로 전환해도 계속합니다.
   조회·더보기·예약·다음 여정의 날짜와 구간 입력에도 같은 방식이 적용됩니다.
4. 도우미 창은 최소화하지 말고 일부가 보이게 두세요. 완전히 가리면 WebView가 정체될 수 있습니다.

도우미의 WebView 화면에만 입력하며 Windows 마우스 포인터를 옮기거나 다른 앱에 키를 보내지 않습니다.
도우미 안을 직접 클릭·스크롤·입력하면 기존 규칙대로 일시정지하거나 중지합니다.
F8은 다른 앱을 사용하는 중에도 중지합니다. 실행 중 입력 방식을 바꾸면 현재 동작이 중지됩니다.
최소화·화면 잠금·절전 상태에서의 계속 실행은 지원하지 않습니다.
알려진 정차 안내만 자동 처리하며 다른 안내는 중지한 뒤 상단 안내 확인에서 직접 확인합니다.
실제 코레일에서 이 입력 방식의 조회·예약 호환성은 미검증입니다.
체크를 끄면 기존 마우스 모드이며 도우미를 맨 앞에 두어야 합니다.

처음 실행과 Telegram 연결
1. Telegram의 공식 BotFather에 /newbot을 보내 본인 봇을 만듭니다.
2. 만든 본인 봇의 대화를 열고 /start를 보냅니다.
3. EXE의 내 봇 토큰 칸에 발급받은 토큰을 입력합니다.
4. Chat ID 찾기에서 본인 대화를 고르거나 본인의 Chat ID를 직접 입력합니다.
   그룹 Chat ID는 직접 입력합니다.
5. 테스트 알림 보내기로 실제 수신을 확인합니다.
6. 예약 완료 알림 사용을 체크하고 저장합니다.

테스트 성공만으로 저장되거나 알림이 켜지지는 않습니다. 나중에는 입력을 저장하지
않습니다. 저장된 연결이 있으면 다음 실행에서 첫 설정창을 건너뜁니다.
설정 → 내 텔레그램 연결에서 언제든 자신의 연결을 변경할 수 있습니다.
텔레그램 연결만 바꾸면 현재 코레일 페이지를 다시 불러오지 않습니다.

원하는 열차 선택
1. 코레일 열기를 누르고 도우미 안의 공식 코레일 화면에서 직접 로그인합니다.
2. 원하는 날짜·출발역·도착역, 직통·총 1명으로 직접 조회합니다.
3. 도우미에서 일반실 또는 특실 등급을 선택합니다.
4. 열차 목록 읽기를 누릅니다. 기본 마우스 모드는 도우미를 앞에 두고, 동시 작업 모드는
   창 일부가 보이게 둡니다. 더보기가 있으면 선택한 입력 방식으로 스크롤하고 눌러
   목록 끝까지 읽습니다. 완료되면 선택 패널이 다시 펼쳐집니다.
5. 한 편이면 드롭다운에서 선택합니다. 여러 편이면 여러 열차번호 (선택)에
   505,541,561처럼 쉼표로 구분해 입력합니다. 비워 두면 드롭다운의 한 편을 사용합니다.
6. 열차 선택 적용을 누릅니다. 날짜·구간·시각·열차·등급을 확인하고 여정 확인란을 체크합니다.

같은 날짜·구간·좌석 등급·총 1명 조건에서 최대 20편까지 지정할 수 있습니다.
입력한 모든 번호가 펼친 조회 결과에 있어야 합니다. 번호를 입력한 순서대로 확인하고,
가격이 표시된 첫 후보를 고릅니다. 가격 선택을 시작한 뒤에는 그 한 편으로 고정하며,
다른 후보로 바꾸거나 여러 건을 예약하지 않습니다.

0.8.3부터 더보기 아래 열차도 선택할 수 있습니다. 번호를 찾지 못했다면
열차 목록 읽기로 목록을 펼친 뒤 다시 적용하세요. 한 번의 목록 펼치기에는
더보기 최대 30회, 결과 최대 2,000행 제한이 있습니다. 다른 날짜 조회는 누르지 않습니다.

새 여정을 고를 때는 공식 화면에서 직접 조회합니다. 설정의 여정 필터가 켜져 있으면
필터와 맞는 후보를 선택하세요. 예약 순서에 추가한 항목은 추가 당시 조건을 별도로
보관하므로 이후 다른 여정을 고르거나 필터를 변경해도 그 항목은 바뀌지 않습니다.
Chrome 로그인 상태가 도우미에 적용되지는 않습니다. 환승·왕복·인접역 조회는 지원하지 않습니다.

열차 선택 저장과 복원
- 적용한 후보의 날짜·구간·열차·시각·등급과 확인 여부를 PC에 저장합니다.
- 다른 페이지로 이동해도 ‘저장한 선택’으로 원래 후보를 표시합니다.
- 같은 조회 조건과 정확히 같은 열차들이 다시 나타나면 새 화면에서 읽고 복원합니다.
  조건이 다르거나 일부 후보가 없으면 실행 가능한 선택으로 사용하지 않습니다.
- 더보기 아래 후보가 빠졌다면 열차 목록 읽기로 목록을 펼치세요.
- 새 후보를 편집할 때는 열차 선택 적용을 눌러야 저장된 선택이 바뀝니다.
- 저장한 선택을 없애려면 선택 초기화를 누릅니다.
- 앱을 다시 켜도 선택을 기억하지만 복원만으로 실행을 시작하지 않습니다.

즉시 예약
후보 중 선택한 등급에 가격이 표시된 열차가 있으면 예약 관리 → 지금 한 번 예약을 누릅니다.
가격 선택 → 인식 가능한 안내 확인 → 예매 1회 → 미결제 예약 확인 → Telegram 전송
순서로 진행합니다. 실제 완료를 확인한 예약만 알리며 버튼 클릭만으로 성공을 알리지 않습니다.

매진 열차 자동 조회
1. 위의 열차 선택과 여정 확인을 완료합니다.
2. 선택 열차 시작에서 간격, 랜덤 지연 (±%), 최대 추가 조회 횟수를 정합니다.
   간격과 횟수는 텍스트 입력칸에 각각 1~2,147,483,647의 정수를 입력합니다.
3. 좌석이 나오면 예약하려면 예약 진행 체크를 켭니다. 기본값은 조회만입니다.
4. 기본 마우스 모드는 도우미를 앞에 둡니다. 마우스 이동만으로는 중지하지 않습니다.
   다른 앱도 쓰려면 시작 전에 동시 작업 (실험)을 체크하고 창 일부가 보이게 둡니다.

0.8.4부터 5초, 999999회, 9999999회를 입력해도 해당 값을 그대로 적용합니다.
빈칸·소수·음수·범위 밖 값은 명시적으로 오류를 표시하고 시작을 막습니다.
입력한 값을 다른 값으로 몰래 보정하지 않습니다.

랜덤 지연은 0~100%이며 기본값 0%는 입력한 간격 그대로 기다립니다.
예: 간격 5초·랜덤 지연 0% → 5초, 간격 5초·20% → 매번 4~6초 중에서 정합니다.
범위는 간격 × (1 ± 비율)이며, 0초 대기를 막기 위해 실제 대기는 최소 1초입니다.
300초 상한은 없습니다.
첫 재조회 전, 그리고 이전 요청의 결과 확인 완료 후 다음 재조회 전에 한 번씩 정합니다.
5초 설정은 결과 확인 후 5초 대기이며 조회 버튼을 정확히 5초마다 누른다는 뜻은 아닙니다.
요청 처리 중에는 다음 조회를 겹쳐 보내지 않습니다.
대기 중에는 다시 뽑지 않으며 상태줄에 남은 초가 표시됩니다.
랜덤 지연이 자동화 감지나 이용 제한을 막아 준다는 보장은 없습니다.

간격과 추가 조회 횟수는 각각 1~2,147,483,647의 정수이며 별도 총 실행시간 제한은 없습니다.
기존 10분 총 실행 제한은 제거했습니다. 설정한 추가 조회 횟수는 유지합니다.
예약 옵션은 모든 후보의 선택 등급이 명확한 매진일 때만 재조회합니다.
재조회 후 선택한 후보가 첫 목록에 없으면 모든 후보를 찾을 때까지 더보기를 누릅니다.
처음 선택한 순서를 유지하며, 먼저 보이는 다른 열차로 바꾸지 않습니다.
더보기 끝까지 확인해도 후보가 없거나 좌석 상태를 읽지 못하면 중지합니다.
더보기 클릭 횟수는 최대 추가 조회 횟수와 별도로 셉니다. 조회만 모드는 기존처럼
조회만 반복하며 후보를 찾기 위한 더보기는 누르지 않습니다.
가격 선택을 시작하면 재조회를 해제하고 선택된 한 편의 예약만 진행합니다.

첫 예약 이후 다음 여정을 예약 순서에 넣기
1. 첫 여정을 직접 조회해 후보 열차를 적용하고 여정 확인란을 체크합니다.
2. 예약 관리 → 현재 선택을 순서에 추가를 누릅니다.
3. 이 항목의 간격·랜덤 지연·횟수를 정하고 예약 순서에 추가를 누릅니다.
4. 관리창을 닫고 다음 날짜·구간을 직접 조회합니다. 다음 후보를 적용·확인하고 같은
   방법으로 추가합니다. 설정의 여정 필터가 다르면 먼저 다음 여정에 맞게 변경하세요.
5. 예약 관리에서 대기 항목을 위·아래로 옮겨 순서를 정합니다.
6. 날짜 선택창이 충분히 보이도록 도우미 창을 넓힌 뒤 예약 순서 시작을 누릅니다.
   기본 마우스 모드는 창을 앞에 두고, 다른 앱도 쓰려면 시작 전에 동시 작업 (실험)을 체크합니다.

한 줄이 예약 한 건입니다. 순서는 최대 20건이고 각 항목에는 같은 여정의 후보를
최대 20편까지 저장합니다. 후보 중 한 편의 미결제 예약이 확인되면 그 항목은 완료되며
같은 항목의 나머지 후보를 추가로 예약하지 않습니다.

예: 첫 줄 서울→부산 10월 25일의 101,103 / 둘째 줄 부산→서울 10월 26일의 102,104.
첫 줄 후보 중 한 편 예약 → Telegram 알림 처리 → 둘째 줄 조회와 후보 한 편 예약 순서입니다.
다음 조회는 공식 코레일의 역·날짜 선택창과 조회 버튼을 선택한 입력 방식으로 조작합니다.
동시 작업 모드는 이 새 여정 조회와 뒤이은 예약에도 적용됩니다.
공식 날짜 선택창에서 가능한 범위로 조회 시작 시각을 조정할 수 있지만, 후보 중 가장 이른
출발 시각을 넘기지 않습니다. 예약할 열차의 날짜·구간·시각·등급은 변경하지 않습니다.
작은 창에서는 공식 날짜 선택창의 시간 이동 버튼이 숨겨질 수 있습니다. 필요한 시간이
화면 밖에 있어 진행할 수 없으면 확대 안내와 함께 중지합니다. 창을 넓히고 공식 예약
내역을 확인한 뒤 예약 관리의 결과 확인 후 다시 대기로 해당 항목을 재시작하세요.
예약 단계의 더보기 중 일시정지했다면 저장된 후보와 실제 조회 조건을 검증해 재개합니다.
아직 화면에 나타나지 않은 후보 때문에 선택 확인란이 비어 있어도 그 이유만으로 중지하지 않습니다.

- 예약이 확인된 뒤 Telegram 전송만 실패하면 예약은 완료 상태를 유지합니다.
  알림 때문에 같은 예약을 다시 요청하지 않으며 다음 항목을 진행합니다.
- 예약 결과가 불명확하거나 중간에 중지되면 결과 확인 상태로 남고 다음 항목을 시작하지
  않습니다. 공식 예약 내역을 확인한 뒤 예약 기록 또는 결과 확인 후 다시 대기를 사용하세요.
- 앱을 다시 켜도 순서가 남지만 자동으로 시작하지 않습니다. 중단된 진행 항목은 결과 확인이
  필요합니다. 대기 항목은 예약 순서 시작을 직접 눌러 실행합니다.
- 목록에서 제거는 프로그램의 순서 목록만 정리하며 실제 코레일 예약을 취소하지 않습니다.
- 기본 마우스 모드는 다음 조회 조건 입력이나 알림 처리 중 직접 입력·창 전환 시 순서를 중지합니다.
  동시 작업 모드는 다른 앱의 조작을 허용하지만 도우미를 직접 조작하면 중지합니다.
  F8·모두 중지·최소화는 두 모드 모두 다음 항목 진행까지 중단합니다.

더보기 결과 확인
- 기존 열차가 같은 순서로 남고 새 행이 추가된 상태가 1초간 유지되어야 진행합니다.
- 결과 교체·중복·차단이나 30초간 변화가 없으면 추가 클릭 없이 중지합니다.
- 한 번의 목록 펼치기에는 더보기 최대 30회, 결과 최대 2,000행 제한이 있습니다.

일시정지와 계속
- 가격 선택 전의 대기·조회·더보기 단계에서 기본 모드는 클릭·스크롤·키 입력이나 창 전환 시,
  동시 작업 모드는 도우미를 직접 조작할 때 일시정지합니다. 다른 앱의 클릭·입력·Alt+Tab은
  동시 작업을 중단하지 않습니다. 두 모드 모두 마우스 이동만으로는 일시정지하지 않습니다.
- 단독 실행 중 최소화는 일시정지하며, 예약 순서 실행 중 최소화는 전체 순서를 중지합니다.
- 선택한 열차, 조회 횟수, 다음 조회 예정 시각은 유지합니다. 자동으로 재개하지 않습니다.
  도우미 창을 복원하고 계속을 누르면 기존 화면 조건을 다시 확인한 뒤 진행합니다.
- 이미 조회 또는 더보기 버튼을 눌렀다면 그때부터 30초 안에 결과 갱신을 확인해야 합니다.
  일시정지로 기한이 늘어나지 않으며, 초과하면 추가 클릭 없이 중지합니다.
- 가격 선택 뒤나 예매 요청 뒤에는 기본 모드의 직접 입력·창 전환, 동시 작업 모드의
  도우미 직접 조작으로 중지합니다. 두 모드 모두 최소화하면 중지합니다.
  예매 요청이 있었다면 계속 실행하기 전에 공식 예약 내역에서 결과를 확인하세요.
- F8·모두 중지, 차단·인증 안내, 사용자의 페이지 이동, 설정 변경, 화면 잠금·절전은 완전 중지합니다.
  알 수 없는 안내나 오류에서도 중지합니다.
- 예약 순서가 다음 항목을 위해 진행하는 공식 페이지 이동은 새 조회 조건을 확인한 뒤
  이어갑니다. 중지한 순서는 자동으로 이어가지 않습니다.
일시정지와 중지는 프로그램 동작만 멈추며 실제 코레일 예약을 취소하지 않습니다.

절전 방지
두 입력 모드 모두 자동 조회·예약·완료 확인 실행 중에만 유휴 절전·화면 꺼짐을 방지합니다.
자동으로 켜지고 하단 상태에 표시됩니다. 일시정지 중에는 해제하며 계속 진행할 때 다시 켭니다.
완료·완전 중지·오류·앱 종료 시에도 해제합니다.
Windows 전원 설정은 변경하지 않습니다. 직접 절전 실행, 덮개 닫기, 화면 잠금과
화면보호기는 막지 못합니다.

예약 완료 후
알림은 미결제 예약 확인이며 결제 완료가 아닙니다.
공식 코레일 화면의 결제기한까지 직접 결제해야 예약을 유지할 수 있습니다.
기한이 지나면 미결제 예약은 자동 취소될 수 있습니다.

결과가 불명확하거나 알림이 오지 않을 때
1. 추가 예약 전에 공식 코레일 예약 내역에서 실제 결과를 확인합니다.
2. 예약이 있다면 해당 예약 상세를 열고 필요한 안내를 직접 확인합니다.
3. 예약 관리 → 예약 기록에서 해당 시도를 선택하고 현재 화면에서 완료 확인을 누릅니다.
   화면만 읽으며 추가 예매나 안내 닫기를 하지 않습니다.
4. Telegram 대화에서 실제 수신 여부도 확인합니다.
한 번 제출한 여정은 결과 불명·알림 실패에도 자동으로 다시 예매하지 않습니다.
중복 방지 해제는 실제 예약 취소가 아닙니다. 공식 내역에 해당 예약이 없음을 먼저 확인하세요.

문제 해결과 연습
- Chat ID 찾기가 비어 있으면 토큰에 해당하는 본인 봇에 /start를 보낸 뒤 다시 찾습니다.
- 시험 알림만 오면 알림 사용 체크와 저장을 완료했는지 확인합니다.
- 간격·횟수 오류가 표시되면 각 칸에 1~2,147,483,647의 정수를 입력합니다.
- Windows가 실행을 막으면 표시된 오류와 버전을 기록합니다. EXE는 코드 서명되지 않았습니다.
- 동시 작업 중 진행이 멈추면 도우미를 최소화하거나 완전히 가리지 않았는지 확인합니다.
  실제 코레일 호환성은 미검증이며, 실행이 중지됐다면 공식 예약 결과부터 확인하세요.
- 동시 작업 중 안내 확인 버튼이 나타나면 자동 진행은 중지된 상태입니다. 눌러 내용을 확인하세요.
- 도움말 → 마우스 연습은 실제 예약이나 Telegram 전송 없이 흐름을 확인합니다.
- 도움말 → 화면 진단 저장은 지원하는 조회·예약 상세 영역을 저장합니다.
- 도움말 → 브라우저 진단 저장은 버전과 페이지 이동 상태 등을 저장합니다. 경로는 상태줄에 표시됩니다.
- 수동 진단은 앱을 닫은 뒤 manual-diagnostic.cmd로 시작합니다. 기존 프로필을 유지하며
  자동 조회·예약·알림과 첫 설정창을 사용하지 않습니다. 직접 조회 결과를 확인하는 용도입니다.
