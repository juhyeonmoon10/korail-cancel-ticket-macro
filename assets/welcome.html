코레일 한 장 도우미 · PC 프로그램

선택한 열차의 예약을 진행하고,
완료 확인 알림을 받으세요.

날짜·구간을 직접 조회한 뒤 열차와 등급을 선택하세요. 여러 열차를 고르면 입력한 번호 순서대로 확인해 그중 한 편만 예약합니다. 실제 미결제 예약이 확인될 때만 내 텔레그램 봇으로 알립니다.

0.8.4 · 입력한 조회 간격과 횟수 그대로
5초와 999999회·9999999회를 그대로 적용하며 기존 10분 총 실행 제한을 제거했습니다. 간격과 횟수는 각각 1~2,147,483,647의 정수로 입력하세요. 잘못된 값은 오류를 표시하고 시작을 막습니다. 0.8.4의 실제 코레일 조회·예약, 텔레그램 예약 완료 알림과 밤샘 실행은 검증하지 않았습니다. 이전 이력과 최신 검사 범위는 동봉된 검증결과.txt에 있습니다.

브라우저 환경 비교: 앱을 닫고 배포 폴더의 ‘manual-diagnostic.cmd’를 실행하면 기존 로그인·설정을 유지한 채 도우미 스크립트와 자동 입력 없이 직접 조회할 수 있습니다. 진단 모드에서는 자동 기능을 켤 수 없습니다. ‘브라우저 진단 저장’은 Runtime 버전·페이지 이동 결과·차단 코드만 기록하며 토큰·쿠키·요청 본문을 저장하지 않습니다.

1

여정 설정 후 직접 조회

프로그램 설정에서 구간·날짜·출발 시간대·좌석 등급을 저장하세요. 공식 코레일 화면에서 같은 조건과 인원 1명으로 직접 조회하세요. 저장한 여정이 코레일 조회 화면에 자동 입력되지는 않습니다.

2

한 편 또는 여러 편 선택

‘열차 목록 읽기’를 누르고 도우미 창을 앞에 두세요. 더보기 끝까지 읽은 뒤 선택 패널이 펼쳐집니다. 같은 조회 조건·등급의 열차번호를 ‘505,541,561’처럼 최대 20편까지 입력하거나, 번호 칸을 비우고 드롭다운에서 한 편을 고르세요. ‘열차 선택 적용’을 누르고 여정을 확인한 뒤 상단 ‘선택 열차 예약 (마우스)’으로 시작하세요.

3

내 텔레그램 봇 연결

처음 실행할 때 열리는 설정창에 내 봇 토큰과 Chat ID를 입력하세요. ‘Chat ID 찾기’로 내 대화를 고를 수도 있습니다. 시험 알림 확인 후 저장하면 다음 실행부터 저장한 연결을 사용합니다. ‘나중에’를 누르면 연결 없이 시작합니다. 연결 변경은 상단 ‘텔레그램 설정’에서 할 수 있습니다.

가격 선택과 예약 완료는 다릅니다. 선택 여정과 일치하는 미결제 예약이 확인되면 알립니다. 예약번호 없는 공식 상세 화면은 한 좌석과 남아 있는 결제기한까지 확인하며, 없는 예약번호를 만들지 않습니다. 결제는 공식 화면에 표시된 기한까지 직접 진행하세요. 각 사용자가 자기 봇을 설정하며, 토큰은 현재 Windows 계정으로 암호화해 이 PC에 저장합니다.

‘마우스 자동 조회’의 간격과 최대 추가 조회 횟수는 각각 1~2,147,483,647의 정수로 입력합니다. 별도 총 실행시간 제한은 없습니다. 빈칸·소수·음수·범위 밖 값은 자동 보정하지 않고 오류를 표시하며 시작을 막습니다. 기본값은 조회만, 60초, 랜덤 지연 0%, 10회입니다. 모든 후보가 명확한 매진일 때만 재조회합니다. 예약 옵션에서는 누락된 후보를 더보기에서 찾으며, 끝까지 확인해도 없거나 상태를 읽지 못하면 중지합니다. 가격이 표시된 후보 중 입력 순서가 앞선 한 편을 고정해 한 건만 예약합니다. 예매 요청 후 결과 불명이나 알림 실패에도 다시 예매하지 않습니다.

더보기 후에는 기존 열차 순서가 유지되고 새 행이 추가된 상태가 1초간 유지되어야 진행합니다. 한 번의 목록 펼치기는 더보기 최대 30회·결과 최대 2,000행이며, 더보기 클릭은 추가 조회 횟수와 별도로 셉니다. 결과 교체·중복·차단이나 30초간 변화가 없으면 중지합니다. 조회만 모드는 기존처럼 조회만 반복합니다.

마우스를 움직이기만 하면 실행은 계속됩니다. 가격 선택 전 대기·조회·더보기 중 클릭·스크롤·키 입력이나 창 전환·최소화가 있으면 일시정지하며 선택한 열차·조회 횟수·다음 조회 예정 시각을 유지합니다. 창을 복원하고 ‘계속’을 눌러야 진행합니다. 이미 조회 또는 더보기 버튼을 눌렀다면 클릭 시점부터 30초 안에 결과 갱신을 확인해야 하며, 일시정지로 기한을 연장하지 않습니다.

가격 선택 뒤나 예매 요청 뒤에 클릭·스크롤·키 입력·창 전환·최소화를 하면 중지합니다. 예매 요청이 있었다면 공식 예약 내역을 확인하세요. F8·모두 중지·차단 안내·페이지 이동·설정 변경·화면 잠금·절전은 완전 중지합니다. 일시정지와 중지는 프로그램 동작만 멈추며 실제 예약을 취소하지 않습니다.

랜덤 지연 (±%)은 0~100%이며 기본값 0%는 입력한 간격 그대로 기다립니다. 5초·0%는 5초, 5초·20%는 4~6초 중에서 정합니다. 범위는 간격 × (1 ± 비율)이며 실제 대기는 최소 1초이고 300초 상한은 없습니다. 첫 재조회 전과 이전 요청의 결과 확인 완료 후 다음 재조회 전에 한 번씩 정합니다. 따라서 5초 설정은 결과 확인 후 5초 대기이며 조회 버튼을 정확히 5초마다 누른다는 뜻은 아닙니다. 요청 처리 중에는 다음 조회를 겹쳐 보내지 않습니다. 대기·일시정지 중에는 다시 뽑지 않으며 상태줄에 남은 초가 표시됩니다. 자동화 감지나 이용 제한을 막아 준다는 보장은 없습니다.

절전 방지는 마우스 자동 기능 실행 중에만 켜지며 하단에 상태가 표시됩니다. 일시정지 중에는 해제하고 계속 진행할 때 다시 켭니다. 완료·완전 중지·오류·앱 종료 시에도 해제합니다. Windows 전원 설정은 변경하지 않습니다. 직접 절전 실행, 덮개 닫기, 화면 잠금과 화면보호기는 막지 못합니다.

모의 연습에서는 실제 코레일에 접속하거나 좌석을 예약하지 않으며, 텔레그램도 전송하지 않습니다. 마우스 재조회 연습은 실제와 같은 간격을 사용합니다. ‘이전 연습 화면’의 JavaScript 검사만 약 1초 대기를 사용합니다.

비공식 프로그램입니다. 직통·1명 조회의 일반실·특실 카드 화면을 지원합니다. 환승·왕복·인접역 묶음 조회는 지원하지 않습니다. 사이트 구조나 접근 제한으로 작동하지 않을 수 있으며, 한 장을 예매하더라도 이용 제한이 없다고 보장할 수는 없습니다.

로그인과 결제는 공식 화면에서 직접 진행합니다. 브라우저 프로필에는 로그인 세션과 쿠키가 남을 수 있습니다.
