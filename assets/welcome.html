상단 ‘선택 열차 시작’에서 간격·횟수를 정하세요. 좌석이 나오면 예약하려면 예매 진행을 체크하세요. 후보 중 한 편만 예약합니다.

내 텔레그램 연결

설정 → 내 텔레그램 연결에서 본인의 봇 토큰과 Chat ID를 입력하고, 시험 알림 확인 후 알림 사용을 체크하고 저장하세요. 연결만 바꿔도 열차 선택은 유지합니다. 결제는 공식 화면의 기한 안에 직접 진행하세요.

다음 일정도 예약

예약 관리 → 현재 선택을 순서에 추가로 여정을 담으세요. 다른 날짜·구간도 직접 조회해 담은 뒤 예약 순서 시작을 누르면, 각 항목에서 한 편 예약과 알림 처리를 마친 뒤 다음 항목으로 진행합니다.

다른 앱과 함께 사용

시작 전에 상단 동시 작업 (실험)을 체크하세요. 다른 앱에서 클릭·입력·Alt+Tab 전환을 해도 도우미 웹 화면에만 입력합니다. 매 실행 기본값은 꺼짐입니다. 최소화하지 말고 창 일부를 보이게 두세요. 실제 코레일 호환성은 미검증입니다.

필요할 때 확인하세요

동시 작업 모드의 사용 방법과 제한

상단 ‘동시 작업 (실험)’을 체크한 뒤 ‘선택 열차 시작’ 또는 ‘예약 순서 시작’을 누르세요. ‘열차 목록 읽기’ 전에 체크하면 더보기에도 적용됩니다. 체크 상태는 저장하지 않으며 앱을 켤 때마다 꺼집니다. 실행 중 변경하면 현재 동작을 중지하므로 다시 시작해야 합니다.

도우미의 WebView 화면에만 입력하며 Windows 마우스 포인터를 움직이거나 다른 앱으로 키를 보내지 않습니다. 다른 앱을 클릭하거나 키보드로 입력하고 Alt+Tab으로 전환해도 진행합니다. 도우미 안을 직접 클릭·스크롤·입력하면 기존 규칙대로 일시정지하거나 중지합니다. F8은 다른 앱을 사용하는 중에도 중지합니다.

최소화·화면 잠금·절전 상태에서 계속 실행할 수 없습니다. 다른 창이 완전히 가리면 WebView가 정체될 수 있으므로 도우미 일부가 보이게 두세요. 알려진 정차 안내만 자동 처리하며 다른 안내는 중지한 뒤 상단 ‘안내 확인’에서 직접 확인합니다. 실제 코레일의 이 입력 방식 호환성은 미검증입니다.

선택 복원과 다음 여정 예약 순서

적용한 날짜·구간·후보·등급은 PC에 저장합니다. 다른 페이지에서는 저장한 선택을 보여주며 같은 조회 조건과 정확히 같은 열차·시각·등급이 다시 나타나면 복원합니다. 조건이 다르거나 후보가 빠지면 실행 가능한 선택으로 사용하지 않습니다. 더보기 아래 후보는 ‘열차 목록 읽기’로 펼치세요. ‘선택 초기화’로 저장 선택을 지울 수 있습니다.

첫 여정 선택·확인 → 예약 관리의 ‘현재 선택을 순서에 추가’ → 항목별 조회 설정 저장 → 관리창 닫기 → 다음 날짜·구간 직접 조회·선택·추가 순서입니다. 대기 항목 순서를 정한 뒤 ‘예약 순서 시작’을 누르세요. 한 줄이 예약 한 건이며 최대 20건, 한 항목의 후보는 최대 20편입니다. 추가한 항목은 나중에 선택이나 설정을 바꿔도 그대로 유지합니다.

각 항목의 후보 중 한 편이 실제로 예약되면 그 항목을 완료하고, 텔레그램 알림 처리 뒤 다음 조회로 이동합니다. 선택한 입력 방식으로 공식 역·날짜 선택창을 조작하므로 동시 작업 모드도 새 여정 조회에 적용됩니다. 선택 가능한 조회 시작 시각을 조정하더라도 가장 이른 후보의 출발 시각을 넘기지 않습니다. 예약할 열차의 날짜·구간·시각·등급은 바꾸지 않습니다.

앱을 다시 켜거나 선택을 복원해도 자동 시작하지 않습니다. 중간에 중지되거나 결과를 확인하지 못한 항목은 ‘결과 확인’ 상태로 남습니다. 공식 예약 내역을 먼저 확인하고 관리창의 예약 기록 또는 ‘결과 확인 후 다시 대기’를 사용하세요. ‘목록에서 제거’는 실제 코레일 예약을 취소하지 않습니다.

조회 간격과 여러 열차 선택

같은 조회 조건·등급의 열차번호를 쉼표로 최대 20편까지 입력할 수 있습니다. 번호 칸을 비우면 목록에서 선택한 한 편을 사용합니다. 가격이 표시된 후보 중 입력 순서가 앞선 한 편을 고정해 한 건만 예약합니다. 바로 한 번 예약하려면 ‘예약 관리 → 지금 한 번 예약’을 누르세요.

조회 간격과 최대 추가 조회 횟수는 각각 1~2,147,483,647의 정수입니다. 빈칸·소수·음수·범위 밖 값은 자동 보정하지 않습니다. 기본값은 조회만, 60초, 랜덤 지연 0%, 10회입니다. 5초는 이전 조회 결과 확인 후 5초 대기한다는 뜻이며 요청을 겹쳐 보내지 않습니다. 총 실행시간 제한은 없습니다.

랜덤 지연은 0~100%이며, 간격 × (1 ± 비율) 범위에서 다음 조회 전에 한 번 정합니다. 실제 대기는 최소 1초이며 300초 상한은 없습니다. 5초·20%는 4~6초입니다. 일시정지 중에는 다시 정하지 않습니다. 자동화 감지나 이용 제한을 막아 준다는 보장은 없습니다.

예약 옵션은 모든 후보가 명확한 매진일 때만 재조회합니다. 누락된 후보는 더보기에서 찾으며 끝까지 없거나 상태를 읽지 못하면 중지합니다. 더보기는 목록을 펼칠 때 최대 30회·2,000행까지 처리하고, 추가 조회 횟수와 별도로 셉니다. 기존 순서와 새 행이 1초간 유지되어야 진행하며 결과 교체·중복·차단이나 30초간 변화가 없으면 중지합니다.

일시정지·계속·중지와 절전 방지

마우스를 움직이기만 하면 계속 실행합니다. 가격 선택 전 대기·조회·더보기 중 기본 마우스 모드는 클릭·스크롤·키 입력이나 창 전환 시, 동시 작업 모드는 도우미를 직접 조작할 때 일시정지합니다. 열차 선택·조회 횟수·다음 조회 시각을 유지하며 ‘계속’을 눌러야 진행합니다. 이미 누른 조회·더보기의 결과 확인 기한 30초는 일시정지로 늘어나지 않습니다.

두 모드 모두 단독 실행 중 최소화는 일시정지하지만 예약 순서 실행 중 최소화는 전체 순서를 중지합니다. 다음 조회 조건 입력이나 알림 처리 중 기본 모드는 직접 입력·창 전환 시, 동시 작업 모드는 도우미 직접 조작 시 전체 순서를 중지합니다. 다른 앱의 조작은 동시 작업을 중단하지 않습니다. F8·모두 중지는 다음 항목 진행까지 막습니다.

가격 선택 또는 예매 요청 뒤 기본 모드에서 직접 조작하거나 창을 전환하면 중지합니다. 동시 작업 모드는 도우미 직접 조작 시 중지합니다. 차단 안내·사용자의 페이지 이동·설정 변경·화면 잠금·절전도 완전 중지합니다. 예매 요청이 있었다면 공식 예약 내역을 확인하세요. 일시정지와 중지는 프로그램만 멈추며 실제 예약을 취소하지 않습니다.

절전 방지는 자동 기능 실행 중에만 켜지며 상태줄에서 확인할 수 있습니다. 일시정지·완료·중지·오류·앱 종료 시 해제합니다. Windows 전원 설정은 바꾸지 않으며 직접 절전 실행, 덮개 닫기, 화면 잠금과 화면보호기는 막지 못합니다.

예약 알림·모의 연습·문제 진단

선택 여정과 일치하는 미결제 예약이 확인되어야 텔레그램으로 알립니다. 예약번호가 없는 공식 상세 화면은 한 좌석과 남은 결제기한을 확인합니다. 예약 순서에서는 알림 전송만 실패해도 확인된 예약을 다시 요청하지 않고 다음 항목을 진행합니다. 결과가 불명확하면 다음 항목도 중지합니다. 결제는 직접 진행하세요.

봇 토큰은 현재 Windows 계정으로 암호화해 이 PC에 저장합니다. ‘Chat ID 찾기’로 개인 대화를 선택할 수 있습니다. 처음 설정에서 ‘나중에’를 누르면 연결 없이 시작합니다. 브라우저 프로필에는 로그인 세션과 쿠키가 남을 수 있습니다.

‘도움말 → 마우스 연습’은 실제 코레일 예약이나 텔레그램 전송을 하지 않습니다. 마우스 재조회 연습은 실제 설정 간격을 사용하고, ‘이전 연습 화면’의 JavaScript 검사만 약 1초 대기를 사용합니다.

직접 조회를 비교하려면 앱을 닫고 배포 폴더의 ‘manual-diagnostic.cmd’를 실행하세요. 로그인·설정을 유지하며 도우미 스크립트와 자동 입력 없이 조회할 수 있습니다. ‘브라우저 진단 저장’은 Runtime 버전·페이지 이동 결과·차단 코드를 기록하고 토큰·쿠키·요청 본문은 저장하지 않습니다.

비공식 프로그램입니다. 직통·1명 조회의 일반실·특실 카드 화면을 지원하며 환승·왕복·인접역 묶음 조회는 지원하지 않습니다. 사이트 구조나 접근 제한에 따라 작동하지 않을 수 있습니다.

로그인과 결제는 공식 코레일 화면에서 직접 진행하세요.
